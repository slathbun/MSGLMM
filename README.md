# MSGLMM
Hamiltonian Markov Chain algorithm for fitting Multivariate Spatial Generalized Mixed effects Models with Linear Model of Coregionalization for latent multivariate Gaussian random field.


## STAN Code

Stan code is partitioned into several sections including the DATA, TRANSFORMED DATA, PARAMETERS, TRANSFORMED PARAMETERS, MODEL, and GENERATED QUANTITIES sections. The DATA section is used to describe the input data. It includes the number of observations (NObs), the number of unique sites (NSites), the number of dependent variables (P), the number of independent variables (K), and the number of latent random fields (Q) in the LMC. This is followed by the NObs X r design matrix X, and the matrix Loc of unique x,y coordinates of study sites. After this, each input variable is specified as an NObs x 1 vector, from Z_1,...,Z_p. Discrete variables are specified as integer level variables with a lower bound of zero, and continuous variables are specified as real variables. Finally, the NObs x 1 vector Site is specified, which contains the unique site number for each of the observations.

The \textit TRANSFORMED DATA section creates the NObs x NSite matrix mapping each of the observations to the study sites.

The PARAMETERS and TRANSFORMED sections are used to specify the model parameters. The PARAMETERS are parameters that may be specified directly, such as the P x r matrix of regression coefficients $\mathbf{B}$; here under the name 'betas', and $\sigma_{\delta}^2$ (vardelta) for the log normally distributed variable \textit{logexec}. Additional parameters include the differences (diff) between range parameters for the latent random fields $\xi_1\cdots,\xi_q$, and the components $\Upsilon$ and $\mu_{\mathbf{A}}$ of the matrix normal model $\text{MN}\left(\mu_{\mathbf{A}},\Upsilon,\Phi\right)$. The collection of Q $\text{Nsite}\times 1$ vectors $w$ are used to generate the latent random fields $\xi_1,\cdots,\xi_q$ using the method of Cholesky decomposition. The \textit{transformed parameters} section is used to compute the remaining parameters of interest including the ranges $\alpha_1,\cdots,\alpha_q$, and the coregionalization matrix $\mathbf{A}$. First, the dimensions of each of these parameters must be specified, the $\text{Q}\times1$ vector $\alpha$ (alpha), and the $\text{P}\times\text{Q}$ matrix $\mathbf{A}$. To generate samples from the matrix normal distribution, the $\text{Q}\times\text{Q}$ matrix L\_upsilon must also be specified, which will be equal to the Cholesky decomposition of $\Upsilon$. The remainder of the \textit{transformed parameters} section is comprised of code for computing $\alpha$ from diff, generations of samples from the matrix normal distribution in two steps, the first being the Cholesky decomposition L\_upsilon of $\Upsilon$ and the second the computation of $\mathbf{A}=\mu_{\mathbf{A}}\Upsilon^{1/2}$, where $\Upsilon^{1/2}$ is L\_upsilon. 

The remaining details of the model are specified in the \textit{model} section. First, the dimensions of the variables of the model must be specified including the $P$ $\text{NObs}\times1$ canonical vectors $\eta_1,\cdots,\eta_P$, the $\text{Q}$ covariance matrices $\Psi_1,\cdots,\Psi_Q$ of the random fields $\xi_1,\cdots,\xi_Q$, their  corresponding Cholesky decompositions $\Psi_1^{1/2},\cdots,\Psi_Q^{1/2}$ (denoted by L\_Psi), the latent random fields $\xi_1,\cdots,\xi_Q$, and the latent random field $\varepsilon=\mathbf{A}\xi$. The remainder of the \textit{model} section is comprised of the computation of the latent random fields $\xi$, the latent random fields $\varepsilon$, the canonical vectors $\eta$, and specification of the priors, and finally the distributions of the individual outcomes. For each $i=1,\cdots,Q$, the Cholesky method is used to generate realizations of the latent random fields $\xi_i=\Psi\left(\alpha_i\right)^{1/2}w$ at the NSite sample sites, where $w\sim\text{N}\left(0,\mathbf{I}_{NSite}\right)$ as generated in the first line under the specification of the priors, and $\Psi\left(\alpha_i\right)^{1/2}$ is the Cholesky decomposition of $\Psi\left(\alpha_i\right)$ which is computed using the 'gp\_exponential\_cov' function of STAN. Next, we compute $\varepsilon=\mathbf{A}\xi$. For each outcome $i$, the canonical vector is $\eta_i=X\beta_i+\mathbf{S}\varepsilon$, where $\beta_i$ is the vector of regression coefficients for that variable, and $\mathbf{S}$ is the matrix SiteToObs mapping observations to study sites.
